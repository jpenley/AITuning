# Plan: notes on invoices

## Goal

Staff want a short free-text note on an invoice (for example "PO 4471, net 30"). The note is optional, at most 500 characters, and is shown to the invoice's owner and to admins.

## Approach

1. Extend `create(customerId, lines, dueDate, notes)` in `src/services/invoices.js`: if `notes` is given it must be a string; trim it, reject it with an error when longer than 500 characters, and store it as `notes`. When absent, store an empty string.
2. In `src/routes/invoices.js`, pass `req.body.notes` through as the fourth argument in `create`.
3. Existing invoices in the data file have no `notes` field. Add a small `withNotes(invoice)` helper that returns the invoice with `notes: invoice.notes ?? ''`, and apply it to every invoice the service returns (`list`, `get` and the `change` helper), so old records read as empty rather than missing. Do not rewrite the stored data.
4. No routing or authorization changes: `show` and `list` already limit customers to their own invoices, and only admins can create invoices.

## Acceptance criteria

- An invoice created without notes has `notes` equal to `''`.
- A note of 500 characters is accepted and returned; 501 is rejected.
- An invoice that was stored before this change reads back with `notes` equal to `''`.
- A customer still cannot read another customer's invoice or its note.

## Verification

Add three cases to `test/invoices.test.js`, which `npm test` already runs: default notes, the 500 and 501 limits, and a legacy record without the field. Run `npm test`.
