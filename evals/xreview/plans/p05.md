# Plan: download an invoice as a PDF

## Goal

Customers and staff can download any invoice they can see as a PDF, to file or forward.

## Approach

1. Add `GET /invoices/:id/pdf` to the route table in `src/server.js`, handled by a new `pdf` function in `src/routes/invoices.js`.
2. The handler authenticates with `session.requireAuth(req)`, loads the invoice with `invoices.get(params.id)` and renders it to a PDF.
3. Render with the `pdfkit` package: add it to `package.json` under `dependencies`, and `npm install` it. The PDF shows the invoice id, the due date, one row per line item, and the total formatted with `formatCents`.
4. Send the bytes with `content-type: application/pdf` and a `content-disposition: attachment; filename=<id>.pdf` header.
5. Extend the route table's response handling in `src/server.js` so a handler may return a `Buffer` body instead of JSON.

## Acceptance criteria

- A logged-in user who requests `/invoices/:id/pdf` for one of their invoices gets a PDF that opens in a viewer.
- The PDF lists every line and the correct total.
- Requests without a valid token get 401.

## Verification

Run `npm test`. Then start the server, request a PDF with curl and open it.
