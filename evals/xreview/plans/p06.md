# Plan: webhook when an invoice is paid

## Goal

Customers who run their own systems want to be told when an invoice is paid. Let a customer register a URL, and call it when one of their invoices is paid. Receivers must be able to check that a call really came from Ledgerly.

## Approach

1. Add an optional `webhookUrl` to customers: accept it in `POST /customers` and store it on the record in `src/services/customers.js`.
2. In `src/services/payments.js`, after `invoices.markPaid(...)` succeeds, look up the customer and, if they have a `webhookUrl`, send `POST <webhookUrl>` with the JSON body `{ event: 'invoice.paid', invoice }` using the built-in `fetch`.
3. If the call fails or returns a non-2xx status, retry up to 3 times with a 2-second pause between tries, then log the failure with `console.error` and carry on.
4. Return the paid invoice to the caller of `pay` as before.

## Acceptance criteria

- Paying an invoice for a customer with a `webhookUrl` results in one POST to that URL with the event body.
- Paying an invoice for a customer without one behaves exactly as today.
- A receiver that is down does not stop the invoice from being marked paid.

## Verification

Add a test that starts a local HTTP server, sets it as a customer's `webhookUrl`, pays an invoice and asserts the local server received the event. Run `npm test`.
