# Plan: longer, sliding sessions ("stay logged in")

## Goal

People are logged out after 8 hours and complain. Let a session last 30 days as long as it keeps being used, including across server restarts, so a user who logs in once a month is never asked again.

## Approach

1. Change the default of `SESSION_TTL_HOURS` in `src/config.js` from 8 to 720.
2. Make the session slide: in `requireAuth` in `src/auth/session.js`, after a valid session is found, set `session.expiresAt = Date.now() + SESSION_TTL_HOURS * 3600 * 1000`.
3. Return the new `expiresAt` in an `x-session-expires` response header so clients can show it.
4. Update the README's description of sessions.

## Acceptance criteria

- A session used at least once every 29 days stays valid.
- A session idle for 30 days is rejected with 401.
- A user who logged in before a server restart is still logged in after it.

## Verification

Add a test that logs in, advances a stubbed clock by 29 days with a request in between, and checks the session is still valid, then advances 30 days idle and checks for 401. Run `npm test`.
