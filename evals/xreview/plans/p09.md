# Plan: an audit log for admin actions

## Goal

For compliance, keep a record of everything an admin does. Every admin action must be logged, and the log must never contain payment card data.

## Approach

1. Add `src/audit.js` with `record(user, req)`, which appends `{ at, userId, method, path, body }` to a new `audit` array in the data file using `store.update`.
2. In the request handler in `src/server.js`, after a handler returns successfully, call `audit.record(user, req)` for any request made by a user whose role is `admin`, so that every admin request is covered without editing each route. The user is the one returned by `session.requireAuth`.
3. Wrap the call in `try/catch` and log a failure with `console.error`, so a problem in the audit log never breaks an admin action.
4. Add `GET /admin/audit` (admin only) that returns the log, newest first.

## Acceptance criteria

- Voiding an invoice as an admin adds a record naming the admin, the path and the time.
- Setting a role adds a record.
- An ordinary customer's requests add nothing.
- `GET /admin/audit` returns the records and is refused for non-admins.

## Verification

Add tests that perform an admin action and check for the record, and a customer action and check for none. Run `npm test`.
