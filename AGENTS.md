# AITuning public distribution

These instructions govern work in this checkout.

## Work in this checkout

Read the relevant collection README before changing a skill. Preserve complete skill folders, supporting files, licenses and the separation of flowstate, trajectory and knowing. Keep local credentials, provider settings, generated results and client caches outside the package.

Use checks that match the changed files. The optional [evaluation toolkit](evals/README.md) provides local checks when selected. A passing local check does not establish provider access, live permission behavior or automatic skill loading. Obtain authorization for paid model runs and external publication.
